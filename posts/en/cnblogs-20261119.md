## Notes - Chapter 7 Building Your Agent Framework

### Overall framework architecture design

Design philosophy of the HelloAgents framework

- Balance between lightweight and teaching-friendly
- Pragmatic choice based on standard APIs: it builds on the OpenAI API specification instead of inventing a new abstraction of its own
- Careful design of a progressive learning path
- Unified "tool" abstraction: everything is a tool

### HelloAgentsLLM extension

- Multiple providers: by default it connects to any OpenAI-compatible service, but it also has to handle differences between providers in environment variable names, default API addresses, recommended models, and so on, so `provider` is introduced and each provider is handled according to this parameter
- Local model invocation: VLLM and Ollama follow the industry-standard API, so `provider="vllm"` or `provider="ollama"` is all you need
- Automatic detection:
  - `_auto_detect_provider`: infers the provider from the environment
    - Highest priority: detect the provider from `XXX_API_KEY`
    - Second priority: determine the provider from `base_url`, matching domains to cloud providers and ports to local models
    - Auxiliary check: analyze the key format to identify specific providers
  - `_resolve_credentials`: completes the concrete parameter configuration based on what `_auto_detect_provider` inferred

### Framework interface implementation

- Message class: a unified message format inside the framework that standardizes how information is exchanged
- Config class: centralized configuration management that is easy to extend and adjust
- Agent abstract base class: the abstract base class for all agents, which gives a unified interface and conventions for implementing different types of agents later

### Framework implementation of agent paradigms

The three paradigms from Chapter 4 are refactored into `ReActAgent`, `ReflectionAgent`, and `PlanAndSolveAgent`. They are easy to call and no longer require writing repetitive code. And because of the underlying `Message` and `Config`, they can store context and manage settings in one place

`FunctionCallAgent` extracts tool call instructions from fields in the response, which is more reliable than having the model write tool call instructions in a fixed format inside its reply.

### Tool system

- Tool base class and registration mechanism design: covers the Tool base class, the ToolRegistry, and the tool management mechanism
  - Tool base class: takes parameters and executes the tool (abstract class)
  - ToolRegistry: maintains a tool dictionary with `tool.name` as the key and the Tool object as the value
  - Tool management mechanism: returns a formatted description string of all available tools
- Custom tool development
- Advanced features of the tool system
  - Tool chaining: runs a specific combination of tools step by step. Register a preset tool chain with `register_chain`, then run it with `execute_chain`
  - Asynchronous tool execution: provides async support for time-consuming tools

      ```python
      import re
      from typing import Optional, Dict, Tuple
      from hello_agents import ReflectionAgent, HelloAgentsLLM, Config, Message

      class MyReflectionAgent(ReflectionAgent):
          """
          Rewritten Reflection Agent: an agent that combines reflection and improvement with scoring
          """

          def __init__(
              self,
              name: str,
              llm: HelloAgentsLLM,
              system_prompt: Optional[str] = None,
              config: Optional[Config] = None,
              max_steps: int = 5,
              custom_prompts: Optional[Dict[str, str]] = None,
              score_threshold: float = 8
          ):
              super().__init__(name, llm, system_prompt, config)
              self.max_steps = max_steps
              self.score_threshold = score_threshold
              self.prompt_template = custom_prompts if custom_prompts else DEFAULT_PROMPTS
              print(f"✅ {name} initialized, max steps: {max_steps}, score threshold: {score_threshold}")

          def run(self, task: str, **kwargs) -> str:
              """Run the Reflection Agent"""
              current_step = 0

              if self.prompt_template.get("initial") is None:
                  raise ValueError("The initial prompt is not defined. Provide a valid initial prompt.")

              if self.prompt_template.get("reflect") is None:
                  raise ValueError("The reflection prompt is not defined. Provide a valid reflection prompt.")

              if self.prompt_template.get("refine") is None:
                  raise ValueError("The refinement prompt is not defined. Provide a valid refinement prompt.")

              print(f"\n🤖 {self.name} starting on the task: {task}")

              # 1. Initial execution
              prompt = self.prompt_template.get("initial").format(task=task)
              messages = [{"role": "user", "content": prompt}]
              content = self.llm.invoke(messages, **kwargs)
              best_score, best_content = None, content

              # 2. Iteration loop: reflect and refine
              while current_step < self.max_steps:
                  current_step += 1
                  print(f"\n--- Step {current_step} ---")

                  # 1. Build the prompt
                  prompt = self.prompt_template.get("reflect").format(
                      task=task,
                      content=content,
                  )

                  # 2. Call the LLM
                  messages = [{"role": "user", "content": prompt}]
                  response_text = self.llm.invoke(messages, **kwargs)

                  # 3. Parse the output
                  score, analysis = self._parse_output(response_text)
                  print(f"📝 Score: {score}")

                  # Keep the highest-scoring version
                  if score is not None and (best_score is None or score > best_score):
                      best_score, best_content = score, content

                  # 4. Check the completion condition
                  if score is not None and score >= self.score_threshold:
                      final_answer = content
                      self.add_message(Message(task, "user"))
                      self.add_message(Message(final_answer, "assistant"))
                      return final_answer

                  # Don't refine on the last step, since the refined version would never be scored
                  if current_step == self.max_steps:
                      break

                  # 5. Refine
                  prompt = self.prompt_template.get("refine").format(
                      task=task,
                      last_attempt=content,
                      feedback=analysis
                  )
                  messages = [{"role": "user", "content": prompt}]
                  content = self.llm.invoke(messages, **kwargs)

              # Max steps reached: return the highest-scoring version, or the latest version if no score was ever parsed
              final_answer = best_content if best_score is not None else content
              print(f"\n⏰ Max steps reached, returning the highest-scoring version (score: {best_score})")
              self.add_message(Message(task, "user"))
              self.add_message(Message(final_answer, "assistant"))
              return final_answer

          def _parse_output(self, text: str) -> Tuple[Optional[float], str]:
              """Extract the score and analysis from the reflection result"""
              score_match = re.search(r"Score\W*(\d+(?:\.\d+)?)", text)
              analysis_match = re.search(r"Analysis\W*(.*)", text, re.DOTALL)
              score = float(score_match.group(1)) if score_match else None
              analysis = analysis_match.group(1).strip() if analysis_match else text
              return score, analysis
      ```

        ```python
        DEFAULT_PROMPTS = {
            "propose": """You are solving the following task step by step.

        # Task:
        {task}

        # Steps decided so far:
        {steps}

        Give {k} different ideas for the next step. Write only one step per idea, each on its own line, in the following format:

        2. Idea
        """,
            "evaluate": """You are solving the following task step by step.

        # Task:
        {task}

        # Steps decided so far:
        {steps}

        # Candidate ideas for the next step:
        {candidates}

        Decide which candidate is most likely to eventually solve the task, and output in the following format:
        Best: candidate number
        Reason: reason
        """,
            "answer": """Give the final answer to the task based on the steps decided so far.

        # Task:
        {task}

        # Steps decided so far:
        {steps}

        Final answer:
        """
        }

        import re
        from typing import Optional, Dict, List
        from hello_agents import HelloAgentsLLM, Config, Message
        from hello_agents.core.agent import Agent

        class MyToTAgent(Agent):
            """
            Tree-of-Thought Agent: generates several candidate ideas at each step and continues with the best one
            """

            def __init__(
                self,
                name: str,
                llm: HelloAgentsLLM,
                system_prompt: Optional[str] = None,
                config: Optional[Config] = None,
                num_candidates: int = 3,
                max_depth: int = 3,
                custom_prompts: Optional[Dict[str, str]] = None
            ):
                super().__init__(name, llm, system_prompt, config)
                # Number of candidate ideas generated each time
                self.num_candidates = num_candidates
                # Maximum depth of the thought tree
                self.max_depth = max_depth
                self.prompts = custom_prompts if custom_prompts else DEFAULT_PROMPTS
                print(f"✅ {name} initialized, candidates per level: {num_candidates}, max depth: {max_depth}")

            def run(self, task: str, **kwargs) -> str:
                """Run the Tree-of-Thought Agent"""
                steps: List[str] = []
                print(f"\n🤖 {self.name} starting on the task: {task}")

                for depth in range(1, self.max_depth + 1):
                    print(f"\n--- Level {depth} ---")
                    steps_text = self._format_steps(steps)

                    # 1. Generate multiple candidate ideas
                    prompt = self.prompts["propose"].format(
                        task=task,
                        steps=steps_text,
                        k=self.num_candidates,
                    )
                    candidates = self._parse_candidates(self._ask(prompt, **kwargs))
                    if not candidates:
                        print("No candidate ideas parsed, stopping early")
                        break
                    for i, candidate in enumerate(candidates, 1):
                        print(f"Candidate {i}: {candidate}")

                    # 2. Evaluate the candidates and pick the best one
                    candidates_text = "\n".join(f"{i}. {c}" for i, c in enumerate(candidates, 1))
                    prompt = self.prompts["evaluate"].format(
                        task=task,
                        steps=steps_text,
                        candidates=candidates_text,
                    )
                    best = self._parse_best(self._ask(prompt, **kwargs), len(candidates))
                    print(f"Chose candidate {best + 1}")

                    # 3. Continue along the best idea
                    steps.append(candidates[best])

                # 4. Generate the final answer from the chosen path
                prompt = self.prompts["answer"].format(
                    task=task,
                    steps=self._format_steps(steps),
                )
                final_answer = self._ask(prompt, **kwargs)

                self.add_message(Message(task, "user"))
                self.add_message(Message(final_answer, "assistant"))
                return final_answer

            def _ask(self, prompt: str, **kwargs) -> str:
                """Call the LLM"""
                messages = [{"role": "user", "content": prompt}]
                return self.llm.invoke(messages, **kwargs) or ""

            @staticmethod
            def _format_steps(steps: List[str]) -> str:
                """Join the chosen steps into text"""
                if not steps:
                    return "(none yet)"
                return "\n".join(f"Step {i}: {s}" for i, s in enumerate(steps, 1))

            def _parse_candidates(self, text: str) -> List[str]:
                """Extract candidate ideas in the "1. xxx" format"""
                candidates = re.findall(r"^\s*\d+[.、)]\s*(.+)$", text, re.MULTILINE)
                return [c.strip() for c in candidates][: self.num_candidates]

            @staticmethod
            def _parse_best(text: str, n: int) -> int:
                """Extract "Best: number" and return the index. Pick the first candidate if parsing fails"""
                match = re.search(r"Best\W*(\d+)", text)
                if match and 1 <= int(match.group(1)) <= n:
                    return int(match.group(1)) - 1
                return 0
        ```
