### Chapter 5 Subagents and Context Isolation: Teaching the Agent to Delegate

The main motivation behind subagents is context isolation. A subagent returns only its result, not its tool calls or reasoning

So subagents pay off more on complex tasks. For simple questions they take more time and spend extra tokens on the subagent prompt

#### Defining a subagent

```python
from deepagents import create_deep_agent

# Define a research subagent
research_subagent = {
    "name": "researcher",                # Required: unique identifier
    "description": "Researches a specific topic in depth, searches multiple sources, and summarizes them",  # Required: the main agent uses this to decide when to delegate
    "system_prompt": """You are a professional researcher. Your tasks are:
1. Break the research question into several search queries
2. Use internet_search to find relevant information
3. Organize the findings into a concise summary
4. List the key findings and sources

Note: keep the result under 500 words and return only the core findings.""",  # Required: the subagent's own instructions
    "tools": [internet_search],          # Optional, inherited by default. Once specified, it fully replaces the inherited set (no merging)
    "skills": ["/skills/research/"],     # Optional, not inherited from the main agent. When specified, runs its own SkillsMiddleware
}

agent = create_deep_agent(
    model="google_genai:gemini-3.1-pro-preview",
    skills=["/skills/main/"],            # Inherited by the main agent and the general-purpose subagent
    subagents=[research_subagent],       # researcher gets only /skills/research/, not /skills/main/
)
```

- A subagent's system_prompt is not inherited from the main agent, so each subagent should have its own instructions
- Skills are not inherited either. The main agent's skills are passed only to the general-purpose subagent, and other subagents need their own skills paths configured explicitly
- Tools inherit the main agent's tool set by default, but once specified explicitly they are **fully replaced** (not merged)
- Permissions inherit the parent rules when omitted, and when provided explicitly they **replace the whole set** instead of adding to it

#### The general-purpose subagent

Deep Agents comes with a general-purpose subagent by default. It inherits the tools, model, and skills passed explicitly to the main agent

For middleware, it inherits only the main agent's same-name overrides of the default middleware. Middleware that is not part of the default set is not passed to the general-purpose subagent, even if the main agent overrides it by name

**Disabling general-purpose**

If you do not want the general-purpose subagent, you can disable the subagent mechanism entirely

```python
from deepagents import create_deep_agent
from deepagents.profiles import GeneralPurposeSubagentProfile, HarnessProfile, register_harness_profile

# Both steps are required
# Register a Harness Profile for the specified model.
register_harness_profile(
    key="openai:zai-org/GLM-5.2",
    profile=HarnessProfile(
        # Do not exclude SubAgentMiddleware with excluded_middleware. It raises a ValueError
        general_purpose_subagent=GeneralPurposeSubagentProfile(
            enabled=False
        )
    ),
)

agent = create_deep_agent(
    model=model,
    subagents=[],  # Pass no synchronous subagents
)
```

**Overriding general-purpose**

To give general-purpose its own model or tools, override it with the same name

```python
agent = create_deep_agent(
    model=model,  # The main agent reuses the app's default model
    tools=[internet_search],
    subagents=[
        {
            "name": "general-purpose",  # Override the default
            "description": "General-purpose assistant that handles all kinds of delegated tasks",
            "system_prompt": "You are a general-purpose assistant.",
            "tools": [internet_search],
            "model": ChatOpenAI(  # Use a stronger model for the subagent
                model="zai-org/GLM-5.2",
                api_key=os.environ["SILICONFLOW_API_KEY"],
                base_url="https://api.siliconflow.cn/v1",
            ),
        },
    ],
)
```

**Enabling Todo for general-purpose**

TodoListMiddleware is not part of the default middleware, so it is off by default. To enable it, override the subagent by name with one that includes TodoListMiddleware

```python
from deepagents import create_deep_agent
from langchain.agents.middleware import TodoListMiddleware

agent = create_deep_agent(
    model=model,
    middleware=[TodoListMiddleware()],  # Planning for the main agent
    subagents=[
        {
            "name": "general-purpose",  # Override the automatically added default subagent
            "description": "Handles delegated tasks that need planning",
            "system_prompt": "Plan the delegated task, carry it out, and return the result.",
            "middleware": [TodoListMiddleware()],  # Enabled separately for the subagent
        },
    ],
)
```

#### CompiledSubAgent

For more complex cases, CompiledSubAgent lets you bring in a LangGraph workflow as a subagent

The State of the LangGraph graph you pass in must contain a `"messages"` key

```python
from deepagents import create_deep_agent, CompiledSubAgent
from langchain.agents import create_agent

# Create a custom agent graph with LangChain
custom_graph = create_agent(
    model=model,
    tools=[statistical_analysis, generate_chart],
    system_prompt="You are a data analysis expert skilled in statistical analysis and visualization.",
)

# Wrap it as a CompiledSubAgent
data_subagent = CompiledSubAgent(
    name="data-analyzer",
    description="Performs complex data analysis tasks, including statistical analysis and chart generation",
    runnable=custom_graph,  # Pass in the compiled LangGraph graph
)

agent = create_deep_agent(
    model=model,
    subagents=[data_subagent],
)
```

#### Multi-subagent collaboration

The main agent coordinates the subagents' work

```python
import os
from langchain_openai import ChatOpenAI
from deepagents import create_deep_agent
from langchain.agents.middleware import TodoListMiddleware

model = ChatOpenAI(
    # The main agent coordinates several subagents, so a capable model with tool calling is recommended
    model="zai-org/GLM-5.2",
    api_key=os.environ["SILICONFLOW_API_KEY"],
    base_url="https://api.siliconflow.cn/v1",
)

subagents = [
    {
        "name": "data-collector",
        "description": "Collects raw data from multiple sources, including web search and API calls",
        "system_prompt": "You are a data collection expert. Search for and organize relevant data, and return a structured data summary.",
        "tools": [internet_search, api_call],
    },
    {
        "name": "data-analyzer",
        "description": "Runs statistical analysis on the collected data and extracts key insights",
        "system_prompt": "You are a data analysis expert. Analyze the data and extract 3-5 key findings in under 300 words.",
        "tools": [statistical_analysis],
    },
    {
        "name": "report-writer",
        "description": "Writes a professional report based on the analysis results",
        "system_prompt": "You are a technical writing expert. Write a clear, professional report based on the analysis results provided.",
        "tools": [format_document],
    },
]

agent = create_deep_agent(
    model=model,
    middleware=[TodoListMiddleware()],
    system_prompt="""You are a project coordinator. For complex tasks:
1. First make a plan with write_todos
2. Delegate data collection to data-collector
3. Delegate the analysis to data-analyzer
4. Delegate report writing to report-writer
5. Combine the subagents' outputs into the final result""",
```

#### Subagent best practices

- Make the `"description"` specific
- Write a detailed system prompt
- Keep the tool set small
- Choose a model that fits the task
- Keep the returned result short (the whole point is context isolation)
- **Make the stopping condition explicit (the same goes for the main agent: state when each step is done)**

## Practice: Splitting the AI news assistant into subagents

In Task2, the main agent of the [AI news assistant](https://github.com/ryukirin/ai-news-deep-agent) handled all four steps on its own: searching, deduplicating, checking against history, and writing the report. After Chapter 5, each step is delegated to its own subagent, and the main agent plans, delegates, and combines the results.

Repository: [ryukirin/ai-news-deep-agent](https://github.com/ryukirin/ai-news-deep-agent)

### Division of work

| Subagent         | Step                                                                     | Model                             | Returns    |
| ---------------- | ------------------------------------------------------------------------ | --------------------------------- | ---------- |
| news-collector   | Searches for news and collects up to 10 items                            | `structured_model`                | `NewsList` |
| news-categorizer | Checks the collected news for duplicates                                 | `structured_model`                | `NewsList` |
| old-news-checker | Compares with `/history/news_history.txt`, removes past news, and appends new records | `structured_model`                | `NewsList` |
| report-generator | Writes the report from the news                                          | Inherits the main agent's `model` | Text       |

- None of the four subagents specifies `tools`, so they inherit the main agent's `internet_search` and `get_current_time`
- news-collector has `ToolCallLimitMiddleware`, so `internet_search` can be called at most 10 times in one run. `exit_behavior="continue"` means that after the limit is reached, searching stops and the subagent carries on
- The first three subagents use `response_format` to return JSON that matches `NewsList`, so the next subagent receives a news list in the same format

### Prompts for the main agent and subagents

The question in `config.py` now delegates step by step, and the four subagents' system prompts live here too:

```python
USER_PROMPT = """
1. Delegate news collection to news-collector, and move on once 10 relevant news items are collected
2. Pass the collected news to news-categorizer for deduplication, and move on if there are no duplicates
3. Pass the organized news to old-news-checker to check whether any of it is past news, and move on if there is none
4. Delegate report writing to report-generator, write a report named {today's date}.md, and save it in the report/ folder
"""

NEWS_COLLECTOR_PROMPT = "You are a news collection expert. Search for and organize relevant news, and return structured news articles. Collect at most 10 news items."
NEWS_CATEGORIZER_PROMPT = """You are a news classification expert. Check whether the collected news contains duplicates.
- If there are duplicates, delete one of them
Return a structured list of news articles with no duplicates."""
OLD_NEWS_CHECKER_PROMPT = """You are a news review expert. Check whether the collected news is past news already in /history/news_history.txt.
- If an item is not past news, append its title, summary, and source to /history/news_history.txt.
- If an item is past news, skip it
Return a structured list of news articles that contains no past news.
"""
REPORT_GENERATOR_PROMPT = "You are a news report expert. Write a comprehensive report from the collected and classified news articles, and return the report content."
```

### Structured output

`data_model.py` defines the news list the subagents return:

```python
from pydantic import BaseModel, Field

class NewsArticle(BaseModel):
    title: str = Field(description="News article title")
    content: str = Field(description="News article content")
    source: str = Field(description="News article source")

class NewsList(BaseModel):
    articles: list[NewsArticle] = Field(description="List of news articles")
```

### Agent

Subagent definitions are added on top of the Task2 code. Subagents with `response_format` use a model with thinking mode turned off, for the reason given in the comment:

```python
# DeepSeek's thinking mode does not support tool_choice="required", so subagents with response_format use non-thinking mode
structured_model = ChatOpenAI(
    model=config.MODEL_NAME,
    api_key=config.DEEPSEEK_API_KEY,
    base_url=config.BASE_URL,
    extra_body={"thinking": {"type": "disabled"}},
)

# Define the subagent list. Subagents without model / tools automatically inherit the main agent's model and tools
subagents = [
    {
        "name": "news-collector",
        "description": "Collects relevant news from multiple sources",
        "system_prompt": config.NEWS_COLLECTOR_PROMPT,
        "model": structured_model,
        "middleware": [
            ToolCallLimitMiddleware(tool_name="internet_search", run_limit=10, exit_behavior="continue"),
        ],
        "response_format": NewsList,
    },
    {
        "name": "news-categorizer",
        "description": "Classifies and organizes the collected news",
        "system_prompt": config.NEWS_CATEGORIZER_PROMPT,
        "model": structured_model,
        "response_format": NewsList,
    },
    {
        "name": "old-news-checker",
        "description": "Checks whether the news is past news",
        "system_prompt": config.OLD_NEWS_CHECKER_PROMPT,
        "model": structured_model,
        "response_format": NewsList,
    },
    {
        "name": "report-generator",
        "description": "Generates the news report",  
        "system_prompt": config.REPORT_GENERATOR_PROMPT,
    },
]
```
