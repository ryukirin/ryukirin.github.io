# Getting Started with Miro

Reference: [Miro API入門](https://qiita.com/Horie1024/items/e2d541dd5f58655337c5)

## Creating an app

1. [https://miro.com/app/dashboard/](https://miro.com/app/dashboard/) → avatar in the upper right → "Settings" → "Your apps" → "Create new app"

2. Miro asks you to create a team (if you are not in a team yet, you should be able to create one yourself after signing up)

3. The team is created as "Dev team" by default

![](/assets/posts/cnblogs-18245945/image-01.png)

Fill in "App Name". My understanding is that "Expire user authorization token" lets you expire tokens that have already been issued, which is more secure.

4. After the app is created, "App Publication Status" lets you publish the app so that other people can use it. If you do not plan to, leave it as it is

5. Set permissions under "Permissions". I only needed to add widgets and view boards, so I selected "boards:read" and "boards:write", then clicked the blue "Install app and get OAuth token" button below to get the access token

## Differences from the Web SDK

[Web SDK vs REST API](https://developers.miro.com/docs/miro-web-sdk-vs-rest-apis)

This table seems to be the important part.

> | Feature/requirement | Miro Web SDK | Miro REST APIs |
> | :--- | :---: | :---: |
> | Real-time interaction with users on the board through UI extension points<br>Example: showing a panel with a custom form | ✅ | ❌ |
> | Access items on the board | ✅ | ✅ |
> | Access team data | ❌ | ✅ |
> | Access organization data | ❌ | ✅ |
> | Third-party product integration | Started from a Miro board | Started from a third-party tool |
> | Board opened in a browser or the Miro native app | Board must be open (online) | Board can be open or not (online or offline) |
> | Backend hosting | Not required | Required |
> | Language | Typescript/JavaScript | Any |

## Working with code

### Quick start

[Official documentation](https://developers.miro.com/reference/overview)

In the sandbox, fill in your access token and the required parameters, choose a language (Shell/Node.js/Ruby/PHP/Python), and click "Try It!" to run the request directly.

### Working with code (Python)

These are only the calls I used (I did not use App cards, though).

#### Setup

```
import requests
TOKEN = "YOUR_ACCESS_TOKEN"
```

#### Notes

Each REST API call opens a request. If too many are opened and never closed, they use up resources and cause errors like this:

```
raise ConnectionError(e, request=request)
requests.exceptions.ConnectionError: HTTPSConnectionPool(host='api.miro.com', port=443): Max retries exceeded with url: (the URL that failed) (Caused by NameResolutionError("<urllib3.connection.HTTPSConnection object at 0x000001BABF9570D0>: Failed to resolve 'api.miro.com' ([Errno 11002] getaddrinfo failed)"))
```

So use with to close requests automatically.

```
session = requests.Session()
with session.get(url, headers=headers) as response:
    [handling code]
```

#### Creating a board

- Option 1:

Create the board manually and save its board ID. After creating it, open the board; the URL looks like this:

```
https://miro.com/app/board/{board_id}/
```

The part in braces is the board ID.

- Option 2

```
url = "https://api.miro.com/v2/boards"
headers = {
    "accept": "application/json",
    "content-type": "application/json",
    "authorization": "Bearer " + TOKEN
}
with session.get(url, headers=headers) as response:
    response.raise_for_status()  # Check for request errors
    board_id = response.text['id']
```

#### App cards and regular cards

- App card: shows data from a third-party app inside the card, like a preview card. For a detailed example, see → [the official App card introduction](https://developers.miro.com/docs/app-card)

- Regular card: a card that can show a title

Creating an App card

```
# Requires board_id

url = "https://api.miro.com/v2/boards/" + board_id + "/app_cards"

payload = { "data": {
    	# Array; each element is one custom field
        "fields": [
            {
                # Fill color of the custom field
                "fillColor": "#2fa9e3",
                # Shape of the icon in the field: "square"/"round"(Default)
                "iconShape": "square",
                # Text color
                "textColor": "#1a1a1a",
                # Icon URL
                "iconUrl": "https://cdn-icons-png.flaticon.com/512/5695/5695864.png",
                # Text shown when the field is clicked or hovered
                "tooltip": "Completion status indicator",
                # Displayed content
                "value": "Status: in progress"
            }
        ],
    	# Card description
        "description": "Sample app card description",
    	# Card display text
        "title": "sample app card item",
    	# Whether the card is connected and synced with its source; returns disabled when the source is deleted
    	# "disconnected"(Default)/connected/disabled
        "status": "disconnected"
    } 
    """
    "style": { "fillColor": fill color },
    "position": {position
        "x": x coordinate,
        "y": y coordinate
    },
    "geometry": {size
        "height": height,
        "width": width
    },
    "parent": { "id": parent item id }
    """}
headers = {
    "accept": "application/json",
    "content-type": "application/json",
    "authorization": "Bearer " + TOKEN
}

with session.post(url, json=payload, headers=headers) as response:
    response.raise_for_status()  # Check for request errors
    result = json.loads(response.text)
    print(result)
```

#### Creating a connector

```
url = "https://api.miro.com/v2/boards/" + board_id + "/connectors"
payload = {
    "startItem": {"id": id of the start card},
    "endItem": {"id": id of the end card},
    "captions": [{"content": text on the connector}]
}
headers = {
    "accept": "application/json",
    "content-type": "application/json",
    "authorization": "Bearer " + TOKEN
}
with session.post(url, json=payload, headers=headers) as response:
    response.raise_for_status()  # Check for request errors
    result = json.loads(response.text)
    print(result)
```

You can also change the arrow type and line thickness. For details, see [Create connector](https://developers.miro.com/reference/create-connector).

#### Getting item information

- Get information on all items on the board

```
url = "https://api.miro.com/v2/boards/" + board_id + "/items"
headers = {
    "accept": "application/json",
    "authorization": "Bearer " + TOKEN
}  
with session.get(url, headers=headers) as response:
    response.raise_for_status()  # Check for request errors
    # result["data"] is a list; iterate over it with for
    # Each item's id is the 'id' field of an element in result["data"]
    result = json.loads(response.text)
    return result
-----------------------------------
# For a RESPONSE example, see https://developers.miro.com/reference/get-items
```

- Get information on a specific item (you need the item's id)

```
url = "https://api.miro.com/v2/boards/" + board_id + "/cards/" + item_id
headers = {
    "accept": "application/json",
    "authorization": "Bearer " + TOKEN
}
with session.get(url, headers=headers) as response:
    response.raise_for_status()  # Check for request errors
    result = json.loads(response.text)

```

#### Updating card information (you need the card's id)

This example changes the text. For other fields, see [Update card item](https://developers.miro.com/reference/update-card-item).

```
url = "https://api.miro.com/v2/boards/" + board_id + "/cards/" + card_id
payload = {"data": {"title": context}}
headers = {
    "accept": "application/json",
    "content-type": "application/json",
    "authorization": "Bearer " + TOKEN
}
with session.patch(url, json=payload, headers=headers) as response:
    if response.status_code == 200:
        print("successfully")
```

#### Deleting an item (you need the item's id)

```
url = "https://api.miro.com/v2/boards/" + board_id + "/items/" + item_id
headers = {
    "accept": "application/json",
    "authorization": "Bearer " + TOKEN
}
with session.delete(url, headers=headers) as response:
    if response.status_code == 200:
        print("successfully")
```
