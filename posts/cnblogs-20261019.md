## 笔记

### 第五章 子 Agent 与上下文隔离 — 让 Agent 学会委派

子 Agent 的核心设计动机是上下文隔离，子 Agent 只返回结果，调用工具和思考结果不返回

所以在复杂任务中用子 Agent 收益回答一点，简单问题反而会更耗费时间，以及多余的子 Agent prompt 消耗

#### 定义子 Agent

```python
from deepagents import create_deep_agent

# 定义一个研究型子 Agent
research_subagent = {
    "name": "researcher",                # 必填：唯一标识符
    "description": "深入研究特定主题，搜索多个信息源并整理成摘要",  # 必填：主 Agent 靠它决定何时委派
    "system_prompt": """你是一位专业的研究员。你的任务是：
1. 把研究问题拆解为多个搜索查询
2. 用 internet_search 搜索相关信息
3. 整理发现，写成简洁摘要
4. 列出关键发现和信息来源

注意：返回结果控制在 500 字以内，只返回核心发现。""",  # 必填：子 Agent 自己的指令
    "tools": [internet_search],          # 可选，默认继承；显式指定后完全替换（不合并）
    "skills": ["/skills/research/"],     # 可选，不继承主 Agent；指定后独立运行 SkillsMiddleware
}

agent = create_deep_agent(
    model="google_genai:gemini-3.1-pro-preview",
    skills=["/skills/main/"],            # 主 Agent 和 general-purpose 子 Agent 继承此处
    subagents=[research_subagent],       # researcher 只获得 /skills/research/，不获得 /skills/main/
)
```

- 子 Agent 的 system_prompt 不继承主 Agent，每个子 Agent 应有自己专属的指令
- skills 也不继承，主 Agent 的 skills 只会传给 general-purpose 子 Agent，其他子 Agent 需要显式配置自己的 skills 路径
- tools 默认继承主 Agent 的工具集，但一旦显式指定就会**完全替换**（不是合并）
- permissions 省略时继承父规则，显式提供后则**整体替换**而非叠加

#### General-purpose 子 Agent

Deep Agents 默认自带 general-purpose 子 Agent，它继承主 Agent 显式传入的 tools、model 和 skills

中间件的话，只继承主 Agent 对其默认中间件的同名覆盖，也就是说不是默认中间件的，就算主 Agent 同名覆盖了也不会传给 general-purpose 子 Agent

**禁用 general-purpose**

如果不想启用 general-purpose 子 Agent，可以完全禁用子 Agent 机制

```python
from deepagents import create_deep_agent
from deepagents.profiles import GeneralPurposeSubagentProfile, HarnessProfile, register_harness_profile

# 两步缺一不可
# 为指定模型注册 Harness Profile。
register_harness_profile(
    key="openai:zai-org/GLM-5.2",
    profile=HarnessProfile(
        # 不要用 excluded_middleware 来排除 SubAgentMiddleware，会直接抛出 ValueError
        general_purpose_subagent=GeneralPurposeSubagentProfile(
            enabled=False
        )
    ),
)

agent = create_deep_agent(
    model=model,
    subagents=[],  # 不传任何同步子 Agent
)
```

**覆盖 general-purpose**

如果想给 general-purpose 指定模型或者工具，可以同名覆盖

```python
agent = create_deep_agent(
    model=model,  # 主 Agent 复用应用的默认模型
    tools=[internet_search],
    subagents=[
        {
            "name": "general-purpose",  # 覆盖默认
            "description": "通用助手，处理各种委派任务",
            "system_prompt": "你是一个通用助手。",
            "tools": [internet_search],
            "model": ChatOpenAI(  # 子 Agent 用更强的模型
                model="zai-org/GLM-5.2",
                api_key=os.environ["SILICONFLOW_API_KEY"],
                base_url="https://api.siliconflow.cn/v1",
            ),
        },
    ],
)
```

**为 general-purpose 启用 Todo**

TodoListMiddleware 不是默认中间件，所以默认不启用，若想启用，则同名覆盖一个带有 TodoListMiddleware 中间件的子 Agent

```python
from deepagents import create_deep_agent
from langchain.agents.middleware import TodoListMiddleware

agent = create_deep_agent(
    model=model,
    middleware=[TodoListMiddleware()],  # 主 Agent 的规划能力
    subagents=[
        {
            "name": "general-purpose",  # 覆盖自动添加的默认子 Agent
            "description": "处理需要规划的委派任务",
            "system_prompt": "为委派任务制定计划，执行后返回结果。",
            "middleware": [TodoListMiddleware()],  # 子 Agent 单独启用
        },
    ],
)
```

#### CompiledSubAgent

对于更复杂的场景，可以用 CompiledSubAgent 导入一个集成 LangGraph 工作流作为子 Agent

传入的 LangGraph 图的 State 中必须包含 `"messages"` 键

```python
from deepagents import create_deep_agent, CompiledSubAgent
from langchain.agents import create_agent

# 用 LangChain 创建一个自定义 Agent 图
custom_graph = create_agent(
    model=model,
    tools=[statistical_analysis, generate_chart],
    system_prompt="你是数据分析专家，擅长统计分析和可视化。",
)

# 包装为 CompiledSubAgent
data_subagent = CompiledSubAgent(
    name="data-analyzer",
    description="执行复杂的数据分析任务，包括统计分析和图表生成",
    runnable=custom_graph,  # 传入编译好的 LangGraph 图
)

agent = create_deep_agent(
    model=model,
    subagents=[data_subagent],
)
```

#### 多子 Agent 协作模式

主 Agent 协调子 Agent 工作

```python
import os
from langchain_openai import ChatOpenAI
from deepagents import create_deep_agent
from langchain.agents.middleware import TodoListMiddleware

model = ChatOpenAI(
    # 主 Agent 负责协调多个子 Agent，建议使用能力较强、支持工具调用的模型
    model="zai-org/GLM-5.2",
    api_key=os.environ["SILICONFLOW_API_KEY"],
    base_url="https://api.siliconflow.cn/v1",
)

subagents = [
    {
        "name": "data-collector",
        "description": "从多个来源收集原始数据，包括网络搜索和 API 调用",
        "system_prompt": "你是数据收集专家。搜索并整理相关数据，返回结构化的数据摘要。",
        "tools": [internet_search, api_call],
    },
    {
        "name": "data-analyzer",
        "description": "对收集到的数据进行统计分析，提取关键洞察",
        "system_prompt": "你是数据分析专家。分析数据并提取 3-5 个关键发现，控制在 300 字以内。",
        "tools": [statistical_analysis],
    },
    {
        "name": "report-writer",
        "description": "根据分析结果撰写专业报告",
        "system_prompt": "你是技术写作专家。根据提供的分析结果撰写清晰、专业的报告。",
        "tools": [format_document],
    },
]

agent = create_deep_agent(
    model=model,
    middleware=[TodoListMiddleware()],
    system_prompt="""你是一位项目协调者。面对复杂任务时：
1. 先用 write_todos 制定计划
2. 将数据收集委派给 data-collector
3. 将分析工作委派给 data-analyzer
4. 将报告撰写委派给 report-writer
5. 整合各子 Agent 的输出，形成最终结果""",
    subagents=subagents,
)
```

#### 子 Agent 最佳实践

- `"description"` 描述要具体
- System Prompt 要详细
- 工具集要精简
- 根据任务特点选择合适的模型
- 返回结果要精简（本来就是为了上下文隔离而用的）
- **结束标志要明确（主 Agent 里也是，明确写出每一步的结束标志）**

## 实践：AI 新闻助理拆分为子 Agent

Task2 的 [AI 新闻助理](https://github.com/ryukirin/ai-news-deep-agent) 由主 Agent 一个人完成搜索、查重、比对历史、写报告四步。学完第五章后，把这四步分别委派给四个子 Agent，主 Agent 负责制定计划、委派任务和整合结果。

### 子 Agent 的分工

| 子 Agent         | 负责的步骤                                                    | 模型                    | 返回格式   |
| ---------------- | ------------------------------------------------------------- | ----------------------- | ---------- |
| news-collector   | 搜索新闻，最多收集 10 条                                      | `structured_model`      | `NewsList` |
| news-categorizer | 检查收集到的新闻有没有重复                                    | `structured_model`      | `NewsList` |
| old-news-checker | 和 `/history/news_history.txt` 比对，剔除过往新闻并追加新记录 | `structured_model`      | `NewsList` |
| report-generator | 根据新闻写报告                                                | 继承主 Agent 的 `model` | 文本       |

- 四个子 Agent 都没有指定 `tools`，继承主 Agent 的 `internet_search` 和 `get_current_time`
- news-collector 加了 `ToolCallLimitMiddleware`，一次运行中 `internet_search` 最多调用 10 次。`exit_behavior="continue"` 表示达到上限后不再搜索，子 Agent 继续往下执行
- 前三个子 Agent 用 `response_format` 返回符合 `NewsList` 结构的 JSON，下一步的子 Agent 拿到的是同一种格式的新闻列表

### 主 Agent 和子 Agent 的提示词

`config.py` 里的问题改成了按步骤委派，四个子 Agent 的 system_prompt 也放在这里：

```python
USER_PROMPT = """
1. 将收集新闻的工作委派给news-collector，收集到10条相关新闻就进行下一步
2. 将收集到的新闻交给news-categorizer进行查重，没有重复的就进行下一步
3. 将整理好的新闻交给old-news-checker检查是否属于过往新闻，没有过往新闻就进行下一步
4. 将撰写报告的工作委派给report-generator，写成一份报告{当天日期}.md，存入report/文件夹中
"""

NEWS_COLLECTOR_PROMPT = "你是新闻收集专家。搜索相关新闻并整理，返回结构化的新闻文章。最多收集10条新闻。"
NEWS_CATEGORIZER_PROMPT = """你是新闻分类专家。检查收集到的新闻有没有重复的。
- 如果有重复的就删掉一篇
返回没有重复的结构化的新闻文章列表。"""
OLD_NEWS_CHECKER_PROMPT = """你是新闻审核专家。检查收集好的新闻是否是/history/news_history.txt中的过往新闻。
- 如果没有过往新闻就把新闻标题和摘要和来源追加到/history/news_history.txt中。
- 如果有过往新闻就跳过该新闻
返回没有过往新闻的结构化的新闻文章列表。
"""
REPORT_GENERATOR_PROMPT = "你是新闻报告专家。根据收集和分类的新闻文章生成综合报告，返回报告内容。"
```

### 结构化输出

`data_model.py` 定义了子 Agent 返回的新闻列表：

```python
from pydantic import BaseModel, Field

class NewsArticle(BaseModel):
    title: str = Field(description="新闻文章标题")
    content: str = Field(description="新闻文章内容")
    source: str = Field(description="新闻文章来源")

class NewsList(BaseModel):
    articles: list[NewsArticle] = Field(description="新闻文章列表")
```

### Agent

在 Task2 的代码上加了子 Agent 的定义。带 `response_format` 的子 Agent 用的是关闭思考模式的模型，原因写在注释里：

```python
# DeepSeek 思考模式不支持 tool_choice="required"，带 response_format 的子 Agent 改用非思考模式
structured_model = ChatOpenAI(
    model=config.MODEL_NAME,
    api_key=config.DEEPSEEK_API_KEY,
    base_url=config.BASE_URL,
    extra_body={"thinking": {"type": "disabled"}},
)

# 定义子 Agent 列表 未指定 model / tools 时自动继承主 Agent 的模型和工具
subagents = [
    {
        "name": "news-collector",
        "description": "从多个来源收集相关新闻",
        "system_prompt": config.NEWS_COLLECTOR_PROMPT,
        "model": structured_model,
        "middleware": [
            ToolCallLimitMiddleware(tool_name="internet_search", run_limit=10, exit_behavior="continue"),
        ],
        "response_format": NewsList,
    },
    {
        "name": "news-categorizer",
        "description": "对收集到的新闻进行分类和整理",
        "system_prompt": config.NEWS_CATEGORIZER_PROMPT,
        "model": structured_model,
        "response_format": NewsList,
    },
    {
        "name": "old-news-checker",
        "description": "检查是否属于过往新闻",
        "system_prompt": config.OLD_NEWS_CHECKER_PROMPT,
        "model": structured_model,
        "response_format": NewsList,
    },
    {
        "name": "report-generator",
        "description": "生成新闻报告",  
        "system_prompt": config.REPORT_GENERATOR_PROMPT,
    },
]
```

`create_deep_agent` 只多了 `subagents=subagents` 一个参数：

