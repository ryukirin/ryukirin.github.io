## 笔记-第七章 构建你的Agent框架

### 框架整体架构设计

HelloAgents框架的设计理念

- 轻量级与教学友好的平衡
- 基于标准API的务实选择：建立在 OpenAI 的 API 规范之上而非自创一个新的抽象写法
- 渐进式学习路径的精心设计
- 统一的“工具”抽象：万物皆为工具

### HelloAgentsLLM扩展

- 支持多提供商：默认是连接任何兼容 OpenAI 接口的服务，但也需要处理各个服务商在环境变量命名、默认 API 地址和推荐模型等方面的差异，所以引入 `provider`，根据这个参数分别处理
- 本地模型调用：VLLM 和 Ollama 因为遵循了行业标准 API，所以只用 `provider="vllm"` 或者 `provider="ollama"` 就行
- 自动检测机制：
  - `_auto_detect_provider`：根据环境信息推断服务商
    - 最高优先级：根据 `XXX_API_KEY` 检测对应服务商
    - 次高优先级：根据 `base_url` 判断服务商，域名匹配云服务商，端口匹配本地模型
    - 辅助判断：分析密钥格式判断特定服务商
  - `_resolve_credentials`：根据 `_auto_detect_provider` 的推断结果完成具体的参数配置

### 框架接口实现

- Message 类：框架内统一的消息格式，让信息交流标准化
- Config 类：集中配置管理，方便扩展和调整
- Agent 抽象基类：定义了所有智能体的抽象基类，为后续实现不同类型的智能体提供了统一的接口和规范

### Agent范式的框架化实现

把第四章的三种范式重构成了 `ReActAgent`、`ReflectionAgent`、`PlanAndSolveAgent`，调用方便，不用再编写重复代码，另外因为有底层的 `Message` 和 `Config`，能够存储上下文，也可以统一管理设置

`FunctionCallAgent` 是从响应的字段中提取工具调用指示，比让模型在回复中按格式生成工具调用指示更加可靠。

### 工具系统

- 工具基类与注册机制设计：包括Tool基类、ToolRegistry注册表，以及工具管理机制
  - Tool基类：可以接收参数和执行工具（抽象类）
  - ToolRegistry注册表：维护一个 `tool.name` 为 key，Tool 对象为 value 的工具字典
  - 工具管理机制：可以获取所有可用工具的格式化描述字符串
- 自定义工具开发
- 工具系统的高级特性
  - 工具链式调用机制：特定工具组合按步骤执行，可以通过 `register_chain` 注册预设工具链，然后 `execute_chain` 执行
  - 异步工具执行支持：对耗时工具提供异步支持

        ```python
        class Agent(ABC):
          def run(self, input_text: str, **kwargs) -> str:   # 模板方法，固定流程
              answer = self._execute(input_text, **kwargs)   # 可变步骤，子类实现
              self.add_message(Message(input_text, "user"))
              self.add_message(Message(answer, "assistant"))
              return answer

          @abstractmethod
          def _execute(self, input_text: str, **kwargs) -> str:
              ...

        class SimpleAgent(Agent):
          def _execute(self, input_text: str, **kwargs) -> str:
              return self.llm.invoke([{"role": "user", "content": input_text}])
        ```

      import re
      from typing import Optional, Dict, Tuple
      from hello_agents import ReflectionAgent, HelloAgentsLLM, Config, Message

      class MyReflectionAgent(ReflectionAgent):
          """
          重写的Reflection Agent - 带评分的反思与改进结合的智能体
          """

          def __init__(
              self,
              name: str,
              llm: HelloAgentsLLM,
              system_prompt: Optional[str] = None,
              config: Optional[Config] = None,
              max_steps: int = 5,
              custom_prompts: Optional[Dict[str, str]] = None,
              score_threshold: float = 8
          ):
              super().__init__(name, llm, system_prompt, config)
              self.max_steps = max_steps
              self.score_threshold = score_threshold
              self.prompt_template = custom_prompts if custom_prompts else DEFAULT_PROMPTS
              print(f"✅ {name} 初始化完成，最大步数: {max_steps}，评分阈值: {score_threshold}")

          def run(self, task: str, **kwargs) -> str:
              """运行Reflection Agent"""
              current_step = 0

              if self.prompt_template.get("initial") is None:
                  raise ValueError("初始提示词未定义，请提供有效的初始提示词。")

              if self.prompt_template.get("reflect") is None:
                  raise ValueError("反思提示词未定义，请提供有效的反思提示词。")

              if self.prompt_template.get("refine") is None:
                  raise ValueError("优化提示词未定义，请提供有效的优化提示词。")

              print(f"\n🤖 {self.name} 开始处理问题: {task}")

              # 1. 初始执行
              prompt = self.prompt_template.get("initial").format(task=task)
              messages = [{"role": "user", "content": prompt}]
              content = self.llm.invoke(messages, **kwargs)
              best_score, best_content = None, content

              # 2. 迭代循环：反思与优化
              while current_step < self.max_steps:
                  current_step += 1
                  print(f"\n--- 第 {current_step} 步 ---")

                  # 1. 构建提示词
                  prompt = self.prompt_template.get("reflect").format(
                      task=task,
                      content=content,
                  )

                  # 2. 调用LLM
                  messages = [{"role": "user", "content": prompt}]
                  response_text = self.llm.invoke(messages, **kwargs)

                  # 3. 解析输出
                  score, analysis = self._parse_output(response_text)
                  print(f"📝 评分: {score}")

                  # 记录分数最高的版本
                  if score is not None and (best_score is None or score > best_score):
                      best_score, best_content = score, content

                  # 4. 检查完成条件
                  if score is not None and score >= self.score_threshold:
                      final_answer = content
                      self.add_message(Message(task, "user"))
                      self.add_message(Message(final_answer, "assistant"))
                      return final_answer

                  # 最后一步不再优化，优化出来的版本没有机会打分
                  if current_step == self.max_steps:
                      break

                  # 5. 优化
                  prompt = self.prompt_template.get("refine").format(
                      task=task,
                      last_attempt=content,
                      feedback=analysis
                  )
                  messages = [{"role": "user", "content": prompt}]
                  content = self.llm.invoke(messages, **kwargs)

              # 达到最大步数，返回分数最高的版本。一次都没解析出分数时，返回最后一版
              final_answer = best_content if best_score is not None else content
              print(f"\n⏰ 达到最大步数，返回评分最高的版本（评分: {best_score}）")
              self.add_message(Message(task, "user"))
              self.add_message(Message(final_answer, "assistant"))
              return final_answer

          def _parse_output(self, text: str) -> Tuple[Optional[float], str]:
              """从反思结果中提取评分和分析"""
              score_match = re.search(r"Score\W*(\d+(?:\.\d+)?)", text)
              analysis_match = re.search(r"Analysis\W*(.*)", text, re.DOTALL)
              score = float(score_match.group(1)) if score_match else None
              analysis = analysis_match.group(1).strip() if analysis_match else text
              return score, analysis
      ```

                llm: HelloAgentsLLM,
                system_prompt: Optional[str] = None,
                config: Optional[Config] = None,
                num_candidates: int = 3,
                max_depth: int = 3,
                custom_prompts: Optional[Dict[str, str]] = None
            ):
                super().__init__(name, llm, system_prompt, config)
                # 每次给出的候选思路的个数
                self.num_candidates = num_candidates
                # 思维树的最大层数
                self.max_depth = max_depth
                self.prompts = custom_prompts if custom_prompts else DEFAULT_PROMPTS
                print(f"✅ {name} 初始化完成，每层候选数: {num_candidates}，最大层数: {max_depth}")

            def run(self, task: str, **kwargs) -> str:
                """运行Tree-of-Thought Agent"""
                steps: List[str] = []
                print(f"\n🤖 {self.name} 开始处理问题: {task}")

                for depth in range(1, self.max_depth + 1):
                    print(f"\n--- 第 {depth} 层 ---")
                    steps_text = self._format_steps(steps)

                    # 1. 生成多个候选思路
                    prompt = self.prompts["propose"].format(
                        task=task, 
                        steps=steps_text, 
                        k=self.num_candidates,
                    )
                    candidates = self._parse_candidates(self._ask(prompt, **kwargs))
                    if not candidates:
                        print("没有解析出候选思路，提前结束")
                        break
                    for i, candidate in enumerate(candidates, 1):
                        print(f"候选{i}: {candidate}")

                    # 2. 评估候选思路，选出最优的一个
                    candidates_text = "\n".join(f"{i}. {c}" for i, c in enumerate(candidates, 1))
                    prompt = self.prompts["evaluate"].format(
                        task=task, 
                        steps=steps_text, 
                        candidates=candidates_text,
                    )
                    best = self._parse_best(self._ask(prompt, **kwargs), len(candidates))
                    print(f"选择候选{best + 1}")

                    # 3. 沿最优思路继续
                    steps.append(candidates[best])

                # 4. 根据选出的路径生成最终答案
                prompt = self.prompts["answer"].format(
                    task=task, 
                    steps=self._format_steps(steps),
                )
                final_answer = self._ask(prompt, **kwargs)

                self.add_message(Message(task, "user"))
                self.add_message(Message(final_answer, "assistant"))
                return final_answer

            def _ask(self, prompt: str, **kwargs) -> str:
                """调用LLM"""
                messages = [{"role": "user", "content": prompt}]
                return self.llm.invoke(messages, **kwargs) or ""

            @staticmethod
            def _format_steps(steps: List[str]) -> str:
                """把已选步骤拼成文本"""
                if not steps:
                    return "（还没有）"
                return "\n".join(f"步骤{i}: {s}" for i, s in enumerate(steps, 1))

            def _parse_candidates(self, text: str) -> List[str]:
                """提取 "1. xxx" 格式的候选思路"""
                candidates = re.findall(r"^\s*\d+[.、)]\s*(.+)$", text, re.MULTILINE)
                return [c.strip() for c in candidates][: self.num_candidates]

            @staticmethod
            def _parse_best(text: str, n: int) -> int:
                """提取 "Best: 编号"，返回下标。解析失败时选第一个"""
                match = re.search(r"Best\W*(\d+)", text)
                if match and 1 <= int(match.group(1)) <= n:
                    return int(match.group(1)) - 1
                return 0
        ```
