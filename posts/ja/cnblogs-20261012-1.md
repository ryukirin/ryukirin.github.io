## 試行錯誤の記録

### 環境構築

背景: 当初は Windows だけで作業しており、Ubuntu を入れる予定はなかった。

問題: データベースの設定でエラーが出続けた。

原因: プロジェクトの `.env` が `SEEKDB_EMBED=true` で、SeekDB の組み込みモードを使っている。`pyseekdb` はネイティブライブラリ `pylibseekdb` に依存しており、`uv.lock` での `pylibseekdb` のインストール条件は次のとおり。

```text
(platform_machine == 'arm64' and sys_platform == 'darwin') or sys_platform == 'linux'
```

`pylibseekdb` 1.4.0.post1 には macOS arm64 と Linux（x86_64、aarch64）向けのパッケージしかなく、Windows にはインストールされない。

解決方法: WSL2 の Ubuntu で実行する。

1. PowerShell を開いて `wsl --install` を実行し、完了後に Windows を再起動する。
2. Ubuntu を起動し、Linux ユーザーを作成する。
3. 次のコマンドで D ドライブにアクセスする（`cd D:\...` は `No such file or directory` になる）。

   ```bash
   cd "/mnt/d/资料/资料/公司/个人/deepagent/research_deepagent"
   ```

### バックエンドに接続できない

背景: Ubuntu で `agentseek dev` を実行するとエラーになった。

問題:

- フロントエンドに `ConnectionError: Unable to connect to LangGraph server. ... Failed to fetch` が表示される。
- `agentseek doctor --live` では、フロントエンド（5174）は正常で、バックエンドは `fail langgraph: http://127.0.0.1:2024/health is not reachable.` になる。
- バックエンドのログに `Application startup complete.` が出て `/docs` にも応答するが、その後自動で停止する。最後の行は次のとおり。

  ```text
  Timed out waiting for 'http://localhost:2024' to become ready: <urlopen error [Errno 111] Connection refused>
  ```

- バックエンドに接続できるようになった後、メッセージを送ると `OpenAIConnectionError: Connection error.` になり、LangSmith への送信でも `ProxyError`（`127.0.0.1:7890` への接続拒否）が出る。

原因: `127.0.0.1:7890` が使えず、プロキシ経由のリクエストがすべて失敗している。

- `agentseek-api dev` は起動後、`urllib.request.urlopen` で `http://localhost:2024/ok` と `/health` をポーリングし、バックエンドの準備ができたかを判定する（`agentseek_api/cli.py` の `_wait_for_dev_server_ready`）。`urllib` は `HTTP_PROXY` を読むため、`NO_PROXY` が未設定だと `localhost` へのリクエストもプロキシに送られる。ポーリングがタイムアウトするとランチャーがバックエンドを停止するので、2024 番ポートに接続できない。
- モデル API と LangSmith へのリクエストも同じプロキシを経由する。curl で比較すると、プロキシ経由で `https://api.openai.com/v1/models` にアクセスした場合は `HTTP 000`、`--noproxy '*'` で直接アクセスした場合は `HTTP 401` が返る（リクエストに API Key を付けていないので 401 になる。ネットワークはつながっている）。

解決方法: `agentseek dev` を実行するターミナルと同じターミナルでプロキシを解除し、ローカルアドレスはプロキシを通さないようにする。

```bash
unset HTTP_PROXY HTTPS_PROXY ALL_PROXY http_proxy https_proxy all_proxy
export NO_PROXY="localhost,127.0.0.1,::1"
export no_proxy="$NO_PROXY"
agentseek dev
```

その後、`agentseek doctor --live` の `langgraph` と `frontend` はどちらも `ok` になった。プロキシが必要な場合は、実際に使えるプロキシのアドレスに置き換え、`NO_PROXY` は残す。
