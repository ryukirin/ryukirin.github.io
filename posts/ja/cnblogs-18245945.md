# Miro 入門

参考: [Miro API入門](https://qiita.com/Horie1024/items/e2d541dd5f58655337c5)

## アプリの作成

1. [https://miro.com/app/dashboard/](https://miro.com/app/dashboard/) → 右上のアイコン →「Settings」→「Your apps」→「Create new app」

2. Team の作成を求められる（もともと Team に入っていない場合、アカウントを作ったあと自分で Team を作れるはず）

3. 作成される Team はデフォルトで「Dev team」になる

![](/assets/posts/cnblogs-18245945/image-01.png)

「App Name」を入力する。「Expire user authorization token」は、発行済みのトークンを失効させて管理できるようにする設定で、より安全になると理解している。

4. 作成後に「App Publication Status」があり、アプリを公開して他の人にも使ってもらえる。そのつもりがなければ、そのままにしておけばよい

5. 「Permissions」で権限を設定する。ウィジェットの追加とボードの閲覧だけできればよかったので「boards:read」と「boards:write」を選び、下の青い「Install app and get OAuth token」ボタンを押して Access Token を取得する

## Web SDK との違い

[Web SDK vs REST API](https://developers.miro.com/docs/miro-web-sdk-vs-rest-apis)

重要なのは主にこの表だと思う。

> | 特徴/要件 | Miro Web SDK | Miro REST APIs |
> | :--- | :---: | :---: |
> | UI の拡張ポイントを通じてボード上のユーザーとリアルタイムにやり取りする<br>例: カスタムフォーム付きのパネルを表示する | ✅ | ❌ |
> | ボード上の item へのアクセス | ✅ | ✅ |
> | チームデータへのアクセス | ❌ | ✅ |
> | 組織データへのアクセス | ❌ | ✅ |
> | サードパーティ製品との連携 | Miro ボードから起動 | サードパーティのツールから起動 |
> | ブラウザまたは Miro のネイティブアプリでボードを開く | ボードを開いている必要がある (online) | ボードは開いていてもいなくてもよい (online or offline) |
> | バックエンドのホスティング | 不要 | 必要 |
> | 言語 | Typescript/JavaScript | 任意 |

## コードによる操作

### クイックスタート

[公式ドキュメント](https://developers.miro.com/reference/overview)

サンドボックスに自分の Access Token と必須パラメーター（required）を入力し、言語（Shell/Node.js/Ruby/PHP/Python）を選んで「Try It!」ボタンを押すと、そのまま実行できる。

### コードによる操作（python）

自分が使ったものだけ記録する（ただし App card は使っていない）。

#### 準備

```
import requests
TOKEN = "YOUR_ACCESS_TOKEN"
```

#### 注意点

REST API では、呼び出すたびにリクエストを 1 つ開く。開いたまま閉じずに増やしていくと、リソースを使いすぎてエラーになる。

```
raise ConnectionError(e, request=request)
requests.exceptions.ConnectionError: HTTPSConnectionPool(host='api.miro.com', port=443): Max retries exceeded with url: (エラーになった URL) (Caused by NameResolutionError("<urllib3.connection.HTTPSConnection object at 0x000001BABF9570D0>: Failed to resolve 'api.miro.com' ([Errno 11002] getaddrinfo failed)"))
```

そのため with を使い、リクエストが自動で閉じるようにする。

```
session = requests.Session()
with session.get(url, headers=headers) as response:
    [処理コード]
```

#### ボードの作成

- 方法 1:

手動でボードを作成し、ボード ID を保存しておく。作成後にボードの画面を開くと、URL は次の形になる。

```
https://miro.com/app/board/{board_id}/
```

括弧の中がボード ID である。

- 方法 2

```
url = "https://api.miro.com/v2/boards"
headers = {
    "accept": "application/json",
    "content-type": "application/json",
    "authorization": "Bearer " + TOKEN
}
with session.get(url, headers=headers) as response:
    response.raise_for_status()  # リクエストの例外を確認
    board_id = response.text['id']
```

#### App card と通常の card

- App card: サードパーティのアプリのデータを card の中に表示できる。プレビューカードのようなもので、詳しい例は → [App card の公式紹介](https://developers.miro.com/docs/app-card)

- 通常の card: title を表示できる card

App card の新規作成

```
# board_id を取得済みであること

url = "https://api.miro.com/v2/boards/" + board_id + "/app_cards"

payload = { "data": {
    	# 配列。各要素が 1 つのカスタムフィールドを表す
        "fields": [
            {
                # カスタムフィールドの塗りつぶし色
                "fillColor": "#2fa9e3",
                # フィールド内のアイコンの形。"square"/"round"(Default)
                "iconShape": "square",
                # 文字色
                "textColor": "#1a1a1a",
                # アイコンのリンク
                "iconUrl": "https://cdn-icons-png.flaticon.com/512/5695/5695864.png",
                # フィールドをクリックまたはホバーしたときに表示するテキスト
                "tooltip": "Completion status indicator",
                # 表示内容
                "value": "Status: in progress"
            }
        ],
    	# card の説明
        "description": "Sample app card description",
    	# card の表示テキスト
        "title": "sample app card item",
    	# card がソースに接続され同期しているかの状態。ソースが削除されると disabled が返る
    	# "disconnected"(Default)/connected/disabled
        "status": "disconnected"
    } 
    """
    "style": { "fillColor": 塗りつぶし色 },
    "position": {位置情報
        "x": x 座標,
        "y": y 座標
    },
    "geometry": {サイズ情報
        "height": 高さ,
        "width": 幅
    },
    "parent": { "id": 親 item の id }
    """}
headers = {
    "accept": "application/json",
    "content-type": "application/json",
    "authorization": "Bearer " + TOKEN
}

with session.post(url, json=payload, headers=headers) as response:
    response.raise_for_status()  # リクエストの例外を確認
    result = json.loads(response.text)
    print(result)
```

#### コネクター（connector）の作成

```
url = "https://api.miro.com/v2/boards/" + board_id + "/connectors"
payload = {
    "startItem": {"id": 始点の card の id},
    "endItem": {"id": 終点の card の id},
    "captions": [{"content": コネクター上のテキスト}]
}
headers = {
    "accept": "application/json",
    "content-type": "application/json",
    "authorization": "Bearer " + TOKEN
}
with session.post(url, json=payload, headers=headers) as response:
    response.raise_for_status()  # リクエストの例外を確認
    result = json.loads(response.text)
    print(result)
```

矢印の種類や線の太さも変更できる。詳しくは [Create connector](https://developers.miro.com/reference/create-connector) を参照。

#### item 情報の取得

- ボード上のすべての item の情報を取得する

```
url = "https://api.miro.com/v2/boards/" + board_id + "/items"
headers = {
    "accept": "application/json",
    "authorization": "Bearer " + TOKEN
}  
with session.get(url, headers=headers) as response:
    response.raise_for_status()  # リクエストの例外を確認
    # result["data"] は list 型なので、for で順に取り出せる
    # item の id は result["data"] の各要素の 'id' フィールド
    result = json.loads(response.text)
    return result
-----------------------------------
# RESPONSE の例は https://developers.miro.com/reference/get-items を参照
```

- 特定の item の情報を取得する（item の id がわかっている必要がある）

```
url = "https://api.miro.com/v2/boards/" + board_id + "/cards/" + item_id
headers = {
    "accept": "application/json",
    "authorization": "Bearer " + TOKEN
}
with session.get(url, headers=headers) as response:
    response.raise_for_status()  # リクエストの例外を確認
    result = json.loads(response.text)
    return result
```

#### card 情報の更新（card の id がわかっている必要がある）

ここではテキストの変更を例にする。その他の項目は [Update card item](https://developers.miro.com/reference/update-card-item) を参照。

```
url = "https://api.miro.com/v2/boards/" + board_id + "/cards/" + card_id
payload = {"data": {"title": context}}
headers = {
    "accept": "application/json",
    "content-type": "application/json",
    "authorization": "Bearer " + TOKEN
}
with session.patch(url, json=payload, headers=headers) as response:
    if response.status_code == 200:
        print("successfully")
```

#### item の削除（item の id がわかっている必要がある）

```
url = "https://api.miro.com/v2/boards/" + board_id + "/items/" + item_id
headers = {
    "accept": "application/json",
    "authorization": "Bearer " + TOKEN
}
with session.delete(url, headers=headers) as response:
    if response.status_code == 200:
        print("successfully")
```
