## ノート - 第 7 章 自分の Agent フレームワークを作る

### フレームワーク全体のアーキテクチャ設計

HelloAgents フレームワークの設計思想

- 軽量さと学びやすさのバランス
- 標準 API にもとづく実用的な選択: 新しい抽象化を自作せず、OpenAI の API 仕様の上に構築する
- 段階的な学習ルートを丁寧に設計
- 統一された「ツール」の抽象化: すべてはツール

### HelloAgentsLLM の拡張

- 複数プロバイダーへの対応: デフォルトでは OpenAI 互換インターフェースのサービスならどれにでも接続できるが、環境変数の名前、デフォルトの API アドレス、推奨モデルなどのプロバイダーごとの違いにも対応する必要があるので、`provider` を導入し、このパラメータに応じてそれぞれ処理する
- ローカルモデルの呼び出し: VLLM と Ollama は業界標準の API に従っているので、`provider="vllm"` か `provider="ollama"` を指定するだけでよい
- 自動検出の仕組み:
  - `_auto_detect_provider`: 環境の情報からプロバイダーを推定する
    - 最優先: `XXX_API_KEY` から対応するプロバイダーを検出する
    - 次の優先度: `base_url` からプロバイダーを判断する。ドメインはクラウドのプロバイダーに、ポートはローカルモデルに対応させる
    - 補助的な判断: キーの形式を分析して特定のプロバイダーを判断する
  - `_resolve_credentials`: `_auto_detect_provider` の推定結果にもとづいて具体的なパラメータを設定する

### フレームワークのインターフェース実装

- Message クラス: フレームワーク内で統一されたメッセージ形式で、情報のやり取りを標準化する
- Config クラス: 設定を一か所で管理し、拡張や調整をしやすくする
- Agent 抽象基底クラス: すべてのエージェントの抽象基底クラスで、この後さまざまな種類のエージェントを実装するための統一されたインターフェースと規約を定める

### Agent パラダイムのフレームワーク化

第 4 章の 3 つのパラダイムを `ReActAgent`、`ReflectionAgent`、`PlanAndSolveAgent` にリファクタリングした。呼び出しが簡単で、同じコードを繰り返し書く必要がなくなった。さらに土台に `Message` と `Config` があるので、コンテキストを保存でき、設定もまとめて管理できる

`FunctionCallAgent` はレスポンスのフィールドからツール呼び出しの指示を取り出すので、モデルに決まった形式で応答の中にツール呼び出しの指示を書かせるより信頼性が高い。

使わない場合

```python
prompt = """次のツールを使えます：
- calculator：数式を計算する。引数は数式

ツールを呼び出すときは、次の形式で応答してください：
Action: ツール名[引数]

質問：123 * 456 はいくつ？"""
```

ツール呼び出しの指示が本文 `message.content` に混ざっていて、正規表現で取り出す必要がある

使う場合は、`response` から直接取り出せる

```python
tools = [{
    "type": "function",
    "function": {
        "name": "calculator",
        "description": "数式を計算する",
        "parameters": {
            "type": "object",
            "properties": {
                "expression": {"type": "string", "description": "数式"}
            },
            "required": ["expression"],
        },
    },
}]

response = client.chat.completions.create(
    model="deepseek-chat",
    messages=[{"role": "user", "content": "123 * 456 はいくつ？"}],
    tools=tools,
)

call = response.choices[0].message.tool_calls[0]
tool_name = call.function.name                         # "calculator"
tool_input = json.loads(call.function.arguments)       # {"expression": "123 * 456"}
```

### ツールシステム

- ツール基底クラスと登録の仕組みの設計: Tool 基底クラス、ToolRegistry、ツール管理の仕組みからなる
  - Tool 基底クラス: 引数を受け取ってツールを実行する（抽象クラス）
  - ToolRegistry: `tool.name` をキー、Tool オブジェクトを値とするツールの辞書を管理する
  - ツール管理の仕組み: 利用できるすべてのツールの説明を整形した文字列を取得できる
- カスタムツールの開発
- ツールシステムの高度な機能
  - ツールのチェーン呼び出し: 特定のツールの組み合わせを手順どおりに実行する。`register_chain` で事前定義のツールチェーンを登録し、`execute_chain` で実行する
  - ツールの非同期実行: 時間のかかるツールに非同期実行の仕組みを提供する

3. 7.3 節では、`Message` クラス、`Config` クラス、`Agent` 基底クラスを実装した。次の点を分析せよ:

   - `Message` クラスは `Pydantic` の `BaseModel` でデータを検証している。この設計には実際の運用でどのような利点があるか？
     - 検証が簡単。作成時に検証されるので、形式を間違えると作成した行でエラーになる
     - JSON への変換が簡単
   - `Agent` 基底クラスは `run` と `_execute` の 2 つのメソッドを定義しており、`run` は公開インターフェース、`_execute` は抽象メソッドである。この設計パターンは何と呼ばれるか？どのような利点があるか？
     - 第 7 章では `_execute` の書き方は見当たらなかったが、この書き方はテンプレートメソッドパターンと呼ばれる。共通の流れを `run` で定義し、それぞれに固有の流れは `_execute` に任せてサブクラスで実装する
        ```python
        class Agent(ABC):
          def run(self, input_text: str, **kwargs) -> str:   # テンプレートメソッド、流れは固定
              answer = self._execute(input_text, **kwargs)   # 可変の手順、サブクラスで実装
              self.add_message(Message(input_text, "user"))
              self.add_message(Message(answer, "assistant"))
              return answer

          @abstractmethod
          def _execute(self, input_text: str, **kwargs) -> str:
              ...

        class SimpleAgent(Agent):
          def _execute(self, input_text: str, **kwargs) -> str:
              return self.llm.invoke([{"role": "user", "content": input_text}])
        ```
   - `Config` クラスではシングルトンパターンを使った。シングルトンパターンとは何か、なぜ設定の管理にシングルトンパターンが必要なのかを説明せよ。シングルトンを使わないとどのような問題が起きるか？
     - 第 7 章ではシングルトンパターンは見当たらなかったが、プログラム全体で `Config` を一つだけ作り、設定を使うすべての場所でこのオブジェクトを使うことを指しているはず。そうすると agent の各パラメータの設定の入口が一つにまとまり、変更するときも一か所を変えるだけでよい。使わない場合は設定の管理が面倒になり、変更漏れが起きやすい。

4. 7.4 節では、4 つの `Agent` パラダイムを実際にフレームワーク化して実装した。

   > <strong>ヒント</strong>：これは実践問題なので、実際に手を動かすことをすすめる

   - 第 4 章でゼロから実装した `ReActAgent` とこの章でフレームワーク化した `ReActAgent` を比較し、具体的な改善点を 3 つ挙げて、それらの改善がコードの保守性と拡張性をどう高めたかを説明せよ。
     - ツール: 第 4 章では Agent が自分でツールを探して呼び出し、見つからない場合も Agent が処理していた。フレームワーク化した後はこれらをすべて `ToolRegistry` に任せ、ツールの登録をモジュール化したことで重複したコードが減った
     - プロンプト: 第 4 章では固定の定数だったが、フレームワーク化した後はデフォルトのプロンプトがあるうえ、呼び出すときに自分のプロンプトでデフォルトを上書きでき、ソースコードを修正しなくてよい
     - 呼び出し方: 第 4 章では `ReActAgent` から別のパラダイムに切り替えようとするとコードの修正量が多かったが、フレームワーク化した後はどのパラダイムも呼び出し方が同じなので、修正量が少ない
   - `ReflectionAgent` は「実行-振り返り-改善」のループを実装している。この実装を拡張して「品質スコア」の仕組みを追加せよ: 振り返りのたびに `LLM` に現在のバージョンの出力を採点させ、スコアがしきい値を下回るときだけ改善を続け、そうでなければ早めに終了する。
      ```python
      DEFAULT_PROMPTS = {
          "initial": """
      次の要件に従ってタスクを完了してください:

      タスク: {task}

      完全で正確な回答を出してください。
      """,
          "reflect": """
      次の回答を注意深くレビューし、現在の回答を採点したうえで、考えられる問題点や改善の余地を見つけてください:

      # 元のタスク:
      {task}

      # 現在の回答:
      {content}

      分析結果は必ず次の形式で出力してください:
      Score: 現在の回答のスコア。範囲は 0～10 で、10 は完璧、0 は完全に誤っていることを表す。
      Analysis: 現在の回答の詳しい分析。長所と短所を指摘する。
      """,
          "refine": """
      フィードバックにもとづいて回答を改善してください:

      # 元のタスク:
      {task}

      # 前回の回答:
      {last_attempt}

      # フィードバック:
      {feedback}

      改善した回答を出してください。
      """
      }

      import re
      from typing import Optional, Dict, Tuple
      from hello_agents import ReflectionAgent, HelloAgentsLLM, Config, Message

      class MyReflectionAgent(ReflectionAgent):
          """
          書き直した Reflection Agent。スコア付きで振り返りと改善を組み合わせたエージェント
          """

          def __init__(
              self,
              name: str,
              llm: HelloAgentsLLM,
              system_prompt: Optional[str] = None,
              config: Optional[Config] = None,
              max_steps: int = 5,
              custom_prompts: Optional[Dict[str, str]] = None,
              score_threshold: float = 8
          ):
              super().__init__(name, llm, system_prompt, config)
              self.max_steps = max_steps
              self.score_threshold = score_threshold
              self.prompt_template = custom_prompts if custom_prompts else DEFAULT_PROMPTS
              print(f"✅ {name} の初期化完了、最大ステップ数: {max_steps}、スコアのしきい値: {score_threshold}")

          def run(self, task: str, **kwargs) -> str:
              """Reflection Agent を実行する"""
              current_step = 0

              if self.prompt_template.get("initial") is None:
                  raise ValueError("初期プロンプトが定義されていません。有効な初期プロンプトを指定してください。")

              if self.prompt_template.get("reflect") is None:
                  raise ValueError("振り返りのプロンプトが定義されていません。有効な振り返りのプロンプトを指定してください。")

              if self.prompt_template.get("refine") is None:
                  raise ValueError("改善のプロンプトが定義されていません。有効な改善のプロンプトを指定してください。")

              print(f"\n🤖 {self.name} が問題の処理を開始: {task}")

              # 1. 最初の実行
              prompt = self.prompt_template.get("initial").format(task=task)
              messages = [{"role": "user", "content": prompt}]
              content = self.llm.invoke(messages, **kwargs)
              best_score, best_content = None, content

              # 2. 反復ループ: 振り返りと改善
              while current_step < self.max_steps:
                  current_step += 1
                  print(f"\n--- ステップ {current_step} ---")

                  # 1. プロンプトを組み立てる
                  prompt = self.prompt_template.get("reflect").format(
                      task=task,
                      content=content,
                  )

                  # 2. LLM を呼び出す
                  messages = [{"role": "user", "content": prompt}]
                  response_text = self.llm.invoke(messages, **kwargs)

                  # 3. 出力を解析する
                  score, analysis = self._parse_output(response_text)
                  print(f"📝 スコア: {score}")

                  # スコアが最も高いバージョンを記録する
                  if score is not None and (best_score is None or score > best_score):
                      best_score, best_content = score, content

                  # 4. 完了条件をチェックする
                  if score is not None and score >= self.score_threshold:
                      final_answer = content
                      self.add_message(Message(task, "user"))
                      self.add_message(Message(final_answer, "assistant"))
                      return final_answer

                  # 最後のステップでは改善しない。改善したバージョンには採点される機会がないため
                  if current_step == self.max_steps:
                      break

                  # 5. 改善する
                  prompt = self.prompt_template.get("refine").format(
                      task=task,
                      last_attempt=content,
                      feedback=analysis
                  )
                  messages = [{"role": "user", "content": prompt}]
                  content = self.llm.invoke(messages, **kwargs)

              # 最大ステップ数に達したら、スコアが最も高いバージョンを返す。一度もスコアを解析できなかった場合は最新のバージョンを返す
              final_answer = best_content if best_score is not None else content
              print(f"\n⏰ 最大ステップ数に達したので、スコアが最も高いバージョンを返す（スコア: {best_score}）")
              self.add_message(Message(task, "user"))
              self.add_message(Message(final_answer, "assistant"))
              return final_answer

          def _parse_output(self, text: str) -> Tuple[Optional[float], str]:
              """振り返りの結果からスコアと分析を取り出す"""
              score_match = re.search(r"Score\W*(\d+(?:\.\d+)?)", text)
              analysis_match = re.search(r"Analysis\W*(.*)", text, re.DOTALL)
              score = float(score_match.group(1)) if score_match else None
              analysis = analysis_match.group(1).strip() if analysis_match else text
              return score, analysis
      ```

        ```python
        import re
        from typing import Optional, Dict, List
        from hello_agents import HelloAgentsLLM, Config, Message
        from hello_agents.core.agent import Agent

        class MyToTAgent(Agent):
            """
            Tree-of-Thought Agent。各ステップで候補の考え方を複数生成し、最適なものを選んで続ける
            """

            def __init__(
                self,
                name: str,
                llm: HelloAgentsLLM,
                system_prompt: Optional[str] = None,
                config: Optional[Config] = None,
                num_candidates: int = 3,
                max_depth: int = 3,
                custom_prompts: Optional[Dict[str, str]] = None
            ):
                super().__init__(name, llm, system_prompt, config)
                # 1 回に出す候補の数
                self.num_candidates = num_candidates
                # 思考の木の最大の層数
                self.max_depth = max_depth
                self.prompts = custom_prompts if custom_prompts else DEFAULT_PROMPTS
                print(f"✅ {name} の初期化完了、各層の候補数: {num_candidates}、最大層数: {max_depth}")

            def run(self, task: str, **kwargs) -> str:
                """Tree-of-Thought Agent を実行する"""
                steps: List[str] = []
                print(f"\n🤖 {self.name} が問題の処理を開始: {task}")

                for depth in range(1, self.max_depth + 1):
                    print(f"\n--- 第 {depth} 層 ---")
                    steps_text = self._format_steps(steps)

                    # 1. 候補の考え方を複数生成する
                    prompt = self.prompts["propose"].format(
                        task=task,
                        steps=steps_text,
                        k=self.num_candidates,
                    )
                    candidates = self._parse_candidates(self._ask(prompt, **kwargs))
                    if not candidates:
                        print("候補を解析できなかったので、早めに終了する")
                        break
                    for i, candidate in enumerate(candidates, 1):
                        print(f"候補{i}: {candidate}")

                    # 2. 候補を評価し、最適なものを選ぶ
                    candidates_text = "\n".join(f"{i}. {c}" for i, c in enumerate(candidates, 1))
                    prompt = self.prompts["evaluate"].format(
                        task=task,
                        steps=steps_text,
                        candidates=candidates_text,
                    )
                    best = self._parse_best(self._ask(prompt, **kwargs), len(candidates))
                    print(f"候補{best + 1}を選択")

                    # 3. 最適な考え方に沿って続ける
                    steps.append(candidates[best])

                # 4. 選んだ経路から最終的な答えを生成する
                prompt = self.prompts["answer"].format(
                    task=task,
                    steps=self._format_steps(steps),
                )
                final_answer = self._ask(prompt, **kwargs)

                self.add_message(Message(task, "user"))
                self.add_message(Message(final_answer, "assistant"))
                return final_answer

            def _ask(self, prompt: str, **kwargs) -> str:
                """LLM を呼び出す"""
                messages = [{"role": "user", "content": prompt}]
                return self.llm.invoke(messages, **kwargs) or ""

            @staticmethod
            def _format_steps(steps: List[str]) -> str:
                """選んだステップをテキストにつなげる"""
                if not steps:
                    return "（まだない）"
                return "\n".join(f"ステップ{i}: {s}" for i, s in enumerate(steps, 1))

            def _parse_candidates(self, text: str) -> List[str]:
                """「1. xxx」形式の候補を取り出す"""
                candidates = re.findall(r"^\s*\d+[.、)]\s*(.+)$", text, re.MULTILINE)
                return [c.strip() for c in candidates][: self.num_candidates]

            @staticmethod
            def _parse_best(text: str, n: int) -> int:
                """「Best: 番号」を取り出してインデックスを返す。解析に失敗したら最初の候補を選ぶ"""
                match = re.search(r"Best\W*(\d+)", text)
                if match and 1 <= int(match.group(1)) <= n:
                    return int(match.group(1)) - 1
                return 0
        ```
