LangChain のフレームワークや Harness を使わなくても LangSmith は使える。``@traceable`` デコレーターを任意の Python 関数に付けると、呼び出しのたびに Trace のノードとして記録され、関数同士の入れ子の呼び出しはツリー構造で表示される。

```python
import json, os
from dotenv import load_dotenv
from openai import OpenAI
from langsmith import traceable
from langsmith.wrappers import wrap_openai

load_dotenv(override=True)
# ラップすると、chat.completions.create の呼び出しごとに LLM ノードとして記録される
client = wrap_openai(
OpenAI(api_key=os.environ["OPENAI_API_KEY"], base_url=os.environ["OPENAI_API_BASE"]))

@traceable(run_type="tool")
def get_weather(city: str) -> str:
    return f"It's always sunny in {city}!"

# フレームワークを使わない場合、ツールの Schema は手で書く（1.3 ではフレームワークが関数から自動生成していた）
TOOLS = [{
    "type": "function", 
    "function": {
        "name": "get_weather", 
        "description": "Get weather for a given city.",
        "parameters": {
            "type": "object", 
            "properties": {
                "city": {
                    "type": "string"
                }
            }, 
            "required": ["city"]
        }
    }
}]

@traceable(name="plain-agent")
def run(question: str) -> str:
    messages = [{"role": "user", "content": question}]
    while True:  # 1.1 の model ↔ tools のループを、ここでは自分で書く
        reply = client.chat.completions.create(model=os.environ["AGENTSEEK_MODEL"], messages=messages, tools=TOOLS).choices[0].message
        messages.append(reply.model_dump(exclude_none=True))
        if not reply.tool_calls:
            return reply.content
        for call in reply.tool_calls:
            result = get_weather(**json.loads(call.function.arguments))
            messages.append({"role": "tool", "tool_call_id": call.id, "content": result})

print(run("今日の北京の天気はどうですか？"))
```

### 実践: AI ニュースアシスタント

タスクの「自作のツールを 1 つ追加する」に対応する。第 2 章のリサーチアシスタントをもとに AI ニュースアシスタントを作った。Agent が Tavily でニュースを検索し、重複する報道をまとめたうえで、トピックごとに要約する。

リポジトリ: [ryukirin/ai-news-deep-agent](https://github.com/ryukirin/ai-news-deep-agent)

#### コースとの対応

| コースの内容 | 本プロジェクト |
| --- | --- |
| `ChatOpenAI` と `base_url` で OpenAI 互換モデルに接続 | `agent.py` |
| 自作ツール（引数の型注釈、戻り値の型、docstring） | `tool.py` の `internet_search`、`get_current_time` |
| `TodoListMiddleware` を明示的に追加し、`write_todos` によるタスク計画を有効化 | `agent.py` |
| LangSmith によるトレース | `.env` の `LANGSMITH_*` 変数 |

コースのサンプルからの変更点:

- `internet_search` から `topic` と `include_raw_content` 引数を外し、検索カテゴリをニュース（`topic="news"`）に固定
- `get_current_time` ツールを追加し、モデルが現在の日時を取得できるようにした
- 環境変数は `config.py` でまとめて読み込み、`.env` は `python-dotenv` で読み込む

#### ツール

```python
import config
from tavily import TavilyClient


tavily_client = TavilyClient(api_key=config.TAVILY_API_KEY)


# ツールの三要素: 引数名と型注釈、戻り値の型、docstring
# create_deep_agent はこの三つからツールの Schema を自動生成するので、手書きは不要
def internet_search(query: str, max_results: int = 5) -> dict:
    """Run a web search for the given query.

    Args:
        query: The search query string.
        max_results: Maximum number of results to return.
    """
    return tavily_client.search(
        query, 
        max_results=max_results, 
        topic="news",  # コースのサンプルでは topic をモデルが選ぶが、ここではニュースに固定
    )

# 引数のないツール。モデルはこれを呼んで現在の日時を取得する
def get_current_time() -> str:
    """Get the current time as a string."""
    from datetime import datetime
    return datetime.now().strftime("%Y-%m-%d %H:%M:%S")
```

#### Agent

```python
from langchain_openai import ChatOpenAI
from deepagents import create_deep_agent
from langchain.agents.middleware import TodoListMiddleware

from tool import internet_search, get_current_time
import config

# 第 2 章と同じく、ChatOpenAI + base_url で OpenAI 互換のモデルサービスに接続
model = ChatOpenAI(
    model=config.MODEL_NAME,
    api_key=config.DEEPSEEK_API_KEY,
    base_url=config.BASE_URL,
)

agent = create_deep_agent(
    model=model,
    tools=[internet_search, get_current_time],
    system_prompt="あなたは賢く、計画を立てて要約もできる AI ニュースアシスタントです。最新の AI ニュースを集めて、要約してください。",
    # TodoListMiddleware を明示的に追加し、モデルが write_todos でタスクを計画できるようにする
    middleware=[TodoListMiddleware()],
)

result = agent.invoke(
    {"messages": [{"role": "user", "content": "まず最近の AI ニュースを検索して、重複がないか確認し、最後に要約してください"}]},
)

print(result["messages"][-1].content)
# モデルが write_todos を呼んだ場合、タスクリストは戻り値の todos フィールドに入る
plan = result.get("todos")
if plan:
    print("Todo リスト：")
    for item in plan:
        print(f"  [{item['status']}] {item['content']}")
else:
    print("今回は todos の状態がありません")
```

#### 既知の制限

- 検索の期間を限定していないため、1 週間以上前のニュースが結果に混ざることがある
- system prompt で出典の要件と出力形式を決めていないため、出典リンクのない項目がある
- ツールが Tavily 呼び出しの例外を捕捉していないため、検索でエラーが出ると実行全体が止まる
- 質問が `agent.py` に直接書かれており、コマンドライン引数には対応していない
